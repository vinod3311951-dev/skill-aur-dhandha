# MAGICPATH BRIEF — GLACIER REACH REFERENCE SCENE

Purpose: create the visual composition for the single Factory X Sarhad Sniper Glacier Reach reference mission.

Authoritative contract:
- ../FACTORY_X_FREE_VISUAL_STACK_GLACIER_CONTRACT.md
- Factory X mission truth remains external and MUST NOT be redesigned.

## Deliverable
Create one editable 16:9 game-scene design at 1920×1080 for a premium stylised 2D/2.5D mobile landscape game.

The scene must communicate:
BEAUTIFUL GLACIER LANDSCAPE → SMALL MECHANICAL OBJECTIVE → PRECISION ACTION → LARGE ENVIRONMENT PAYOFF.

## Visual hierarchy

1. Background
- cold blue-white glacier valley;
- distant mountains;
- subtle cloud/fog depth;
- large scenic negative space;
- no generic gradient-only background.

2. Midground
- fictional relay installation physically grounded into icy cliff/terrain;
- mast, dish, cable/power structures and believable mechanical support pieces;
- installation must read as one coherent machine, not separate floating icons.

3. Foreground
- snow/rock framing;
- room for Captain Rudraa treatment at edge of composition;
- no obstruction over the aim zone.

4. Objective
- exposed mechanical coupler/core physically integrated into relay installation;
- visual focal point around normalized x≈0.68, y≈0.42;
- readable at phone scale;
- no cardboard, target board, isolated circle, diamond, rectangle, debug marker or text label.

## Captain Rudraa
Original fictional hero:
- tan/light-brown;
- moustache + beard;
- warm scarf;
- charcoal/graphite clothing;
- teal equipment accents;
- calm precision posture;
- no real insignia, flags or real weapon identity.

## HUD
Gameplay is landscape-first and scene-dominant.
HUD overlays the world and remains visually quiet during observation/aim:
- mission identifier;
- score/ammo only where required;
- scope/binocular controls;
- pause/settings;
- safe-zone aware.
Do not place the game inside a narrow card or utility-style frame.

## Animation-ready separation
Organize the design so these can become independent Phaser layers:
- sky/cloud;
- far mountains;
- mid glacier;
- relay installation;
- mechanical objective;
- cable/power path;
- foreground snow/rock;
- Rudraa;
- atmospheric overlay;
- HUD.

## Success state
Also design the activated state:
- objective flashes/responds;
- conduit/light path energizes;
- dish rotates/changes state;
- distant beacon/system activates;
- scene feels larger after the precise hit.

## Prohibitions
- no copied game UI;
- no photoreal military simulation;
- no real borders/countries/armies;
- no stock cardboard targets;
- no placeholder blocks;
- no stick/mannequin characters;
- no generic floating mission icons;
- no portrait gameplay composition.

## Output expectation
Return editable scene/design layers and a clear layer list that Factory X can map into Phaser.
