# Factory X — Open-Access Launch Law

**Status:** BINDING FOUNDER-WIDE LAUNCH LAW  
**Scope:** every existing Factory X PWA link, preview/staging URL, and future Factory X PWA.  
**Created:** 2026-10-01

## 1. Current launch phase — open access

For the present Factory X launch/pilot phase:

### Games
Every game must expose **all worlds, levels and ordinary playable content from first launch**.

Do not require:
- previous-level completion;
- previous-world completion;
- subscription;
- payment;
- rewarded ad;
- account creation;
- streak;
- referral;
- daily return

to access the next normal level.

Progress still matters for:
- score;
- mastery;
- stars;
- records;
- cosmetics;
- postcards/collections;
- achievements;
- replay goals;
- world/mission completion history.

Progress must not be confused with access gating.

### Utilities
Core utility functions remain open unless a later product-specific founder decision explicitly creates a premium feature.

## 2. Current monetisation state

During the current open-access build phase:
- no subscription gate blocks ordinary progression;
- no ad gate blocks ordinary progression;
- no pay-to-win;
- no forced rewarded ad to continue;
- no deceptive premium placeholder.

## 3. Future monetisation phase

After real traction/subscribers exist, the founder may deliberately open a monetisation phase.

Possible later models:
- clearly labelled ads;
- optional premium/ad-free subscription;
- optional premium convenience/content that does not break fairness or core utility;
- other founder-approved ethical monetisation.

A future subscription/ad decision must be implemented as a **new explicit authority change**.

Do not silently turn today's open-access build into a paywall.

## 4. Game QA gate

Every current/future game PWA must prove, without test/debug bypass:
- every world is selectable on fresh state;
- every level is selectable on fresh state;
- first launch has no progression lock;
- completion records still save correctly;
- rewards/mastery remain meaningful even though access is open;
- no ad/subscription/account prompt blocks play.

## 5. Fresh-chat inheritance

Every current and future Factory X product contract inherits this law automatically.

Product contracts should point here and add only product-specific monetisation details.
