## SPENDING VERIFICATION LAW

NEVER recommend a paid service without:

1. Verifying exact cost (per month, per project, per user).
2. Confirming it fits locked stack (`FACTORY_X_MASTER_FRESH_CHAT_CONTEXT_v4.md` section 15).
3. Providing a FREE alternative if one exists.
4. Flagging as RED STOP if any charge would occur without approval.
